# Pomogator — визуальное демо

Статичное визуальное демо UX Помогатора (мокапы ПК + смартфон, 14 экранов).
Деплоится в Coolify на Beget из этого репозитория (Dockerfile → nginx).

Прод-демо: https://demo.pomogator.imryazapov.ru

Чтобы обновить — отредактировать `index.html`, `git push`, Coolify передеплоит автоматически.
